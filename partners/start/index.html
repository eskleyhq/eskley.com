Open Rowtrace.exe, paste a Smartsheet API token, pick what to back up and where, and run. Each row's attachments land in a folder for that row.

Getting started

How do I run my first backup?

Rowtrace backs up your Smartsheet sheets, their attachments and the data in your reports to a folder you choose, with each row's attachments filed in a folder for that row and a manifest that says which file came from which row. It runs on your Windows computer. Nothing is sent anywhere else.

What do I need before I start?

  • A Windows computer you're logged on to when backups run.
  • A Smartsheet account on smartsheet.com. The EU, Australia and Gov regions aren't supported yet.
  • A Smartsheet API access token. In Smartsheet: Account → Personal Settings → API Access → Generate new access token. Copy it; Smartsheet shows it once.
  • Somewhere to save: a local drive, a OneDrive folder or a network drive.

Rowtrace sees exactly what the token's user can see, no more. If you want a workspace backed up, the token has to come from someone shared to it. A dedicated account works best; Your token and your data explains why.

How partners get Rowtrace.exe: link to the download page once it exists. The download page is a separate draft, and no exe goes out until the clean-machine run has passed.

1. Open Rowtrace

Double-click Rowtrace.exe. There's no installer; it opens in its own window.

What Windows shows the first time (for example "Windows protected your PC", then More info, check the publisher, Run anyway) waits on the clean-machine run, and the publisher name waits on the switch to Eskley LLC.

2. Connect

Paste your token and choose Connect to Smartsheet. Rowtrace saves the token on this computer, encrypted to your Windows user, so you won't paste it again.

3. Your first backup

Choose New backup:

  1. Select items. Tick the workspaces, folders, sheets and reports to back up.
  2. When. Now, once to try it out, or On a schedule: every day or on the weekdays you pick, at a time you choose.
  3. Where. Pick a save location and a folder layout: By row number, flat works for any sheet; By primary column, keep row hierarchy names folders from the first column and nests them like the sheet.
  4. Review, then Back up now or Save schedule.

Backing up a large account for the first time? Choose Plan a first backup instead. It counts what you have and spreads the first full copy over the nights you allow, so no single run takes all night.

4. What do I get?

Each run makes a new timestamped folder, so runs never overwrite each other. Inside it, every sheet has an Excel copy, a folder per row holding that row's attachments, and a manifest (CSV and a readable HTML page) mapping every file to its row and recording what the row said at the time. Earlier versions of an attachment are kept in _versions beside it.

After the first run, each run copies forward what hasn't changed and downloads only what has, so later runs are short. History lists every run, and Open backup folder takes you straight to the result.

What does Windows decide, not Rowtrace?

  • A schedule runs as you, on this computer, only while you're logged on. Lock the screen instead of signing out.
  • A sleeping laptop doesn't run backups. Keep it awake at the scheduled time.
  • By default Windows only starts a scheduled task on mains power. Plug in.
  • If you move Rowtrace.exe, save each schedule again.

What doesn't Rowtrace do yet?

  • It doesn't restore into Smartsheet. It's a backup you can open and read, not a way to put data back.
  • Dashboards aren't backed up.
  • Files linked from Google Drive, OneDrive, Box, Dropbox or a URL are listed in the manifest with their links; the files themselves stay where they are.
  • Sheets in your Sheets folder that aren't in a workspace don't appear yet. Move them into a workspace to back them up.
