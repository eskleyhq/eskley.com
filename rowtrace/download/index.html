TL;DR

Rowtrace is one code-signed Windows program. Download it, double-click it, paste a Smartsheet API token and choose a folder. There is nothing to install and no account to create.

Download Rowtrace

Rowtrace backs up your Smartsheet sheets, their attachments and your reports to a folder you choose, with every attachment filed under the row it came from.

It is in its design-partner phase: a small group of Smartsheet administrators are running it and telling us what breaks. During that phase it is free.

What do I need before I start?

A Windows computer, a Smartsheet API token and somewhere to save the backup.

  • A Windows computer you are signed in to when backups run. Scheduled backups run as you, only while you are signed in.
  • A Smartsheet.com account. Smartsheet EU, Smartsheet AU and Smartsheet Gov accounts are not supported yet.
  • A Smartsheet API access token. In Smartsheet: Account, then Personal Settings, then API Access, then Generate new access token. Smartsheet shows it once, so copy it.
  • Somewhere to save: a local drive, a OneDrive folder or a network drive.

Rowtrace sees exactly what the token's user can see in Smartsheet, no more. To back up a workspace, the token has to come from someone shared to it.

Will Windows warn me when I open it?

GAP 6: what Windows actually shows the first time the signed exe opens on a clean machine

Rowtrace is new, and Windows builds trust in a program as more people run it. If you see "Windows protected your PC", choose More info, check that the publisher matches the one above, then choose Run anyway.

To check the file yourself before you run it, open PowerShell in the folder you saved it to and run:

Get-AuthenticodeSignature .\Rowtrace.exe | Format-List Status, SignerCertificate
Get-FileHash .\Rowtrace.exe -Algorithm SHA256

Status should read Valid, and the hash should match the SHA-256 above.

What happens after I open it?

You connect once, then choose what to back up, when and where.

  1. Connect. Paste your token and choose Connect to Smartsheet. Rowtrace saves the token on this computer, encrypted to your Windows user, so you won't paste it again.
  2. New backup. Tick the workspaces, folders, sheets and reports to back up, choose Now, once or On a schedule, and pick a save location.
  3. Open the result. Each run makes a new timestamped folder holding an Excel copy of each sheet, a folder per row with that row's attachments, and a manifest that says which file came from which row.

The full walkthrough is in the GAP 7: link to the quick-start guide once its page exists. What happens to your token, step by step, is on GAP 8: link to the token page once it exists.

What doesn't Rowtrace do yet?

It doesn't put data back into Smartsheet, and it doesn't back up dashboards.

  • It doesn't restore into Smartsheet. It is a backup you can open and read, not a way to put data back.
  • Dashboards aren't backed up.
  • Sheets in your Sheets folder that aren't in a workspace don't appear yet. Move them into a workspace to back them up.
  • Attachments stored as links to Google Drive, OneDrive, Box, Dropbox or a web address are recorded in the manifest, not downloaded.
