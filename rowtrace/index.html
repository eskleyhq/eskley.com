Backup for Smartsheet

Every attachment, filed under the row it came from.

Rowtrace is a Windows app that backs up your Smartsheet sheets and reports to a folder on your computer or a SharePoint library. Each row's attachments get their own folder, every run is a complete backup in a new folder, and every file is checked after it's written.

Why can't Smartsheet's own backup map attachments to rows?

Because it doesn't write down which row an attachment came from. Every uploaded attachment lands in one folder.

A sheet with 300 rows and 1,000 attachments becomes 1,000 files side by side. Rowtrace keeps the row.

How it works

What actually lands on disk after a run?

Plain folders you can open in File Explorer: one new folder per run, one folder per row.

Each run makes a new folder named for its date and time, so runs never overwrite each other. Inside are your workspace and folder names, an Excel copy of each sheet, and a folder per row holding that row's attachments, the files on its comments and its cell images. Earlier versions of an attachment are kept in _versions beside the current one.

Each sheet gets a manifest, as a CSV and as an HTML file that opens with no network. Each line is one file: its sheet, row number, row label, folder, version, size, uploader and result.

After the first run, unchanged files are copied from the last run's folder and only changed files are downloaded. Every run folder still holds a complete backup.

When a run counts as done
Every downloaded file is checked against the size Smartsheet reported. A run is marked Done only when every item finished, no file is missing, and every manifest and export is confirmed on disk.
Security

Where does my data go, and who can see my API token?

Your backup goes to the folder you pick, and your token goes to Smartsheet. Nowhere else.

1 · paste

You paste it in

Rowtrace uses the token to call the Smartsheet API, and for nothing else. The only servers it talks to are Smartsheet's.

2 · save

It's saved, encrypted, on your computer

Encrypted with Windows' built-in data protection and tied to your Windows user. Copied to another computer, or opened by another Windows user, the saved file can't be read.

3 · revoke

You can take it back at any time

Revoke the token in Smartsheet and Rowtrace can no longer reach your account. Forget this account deletes the local copy.

Your folder, not ours

Backups go to a folder on your computer, such as a local drive, a OneDrive folder or a network share, or to a SharePoint library you grant it. They are plain files, readable without Rowtrace installed.

No account, no usage data

There's no Eskley server and no account to create. Rowtrace has nothing to send usage data to.

Code-signed by Eskley LLC

Rowtrace is a single code-signed Windows program. Windows shows its publisher as Eskley LLC.

Common questions

What do admins ask before they trust a backup tool?

Does Rowtrace restore data back into Smartsheet?

No. It's the backup you can open, read and hand to an auditor, not a way to put data back. The tools that restore, compared.

What does the check actually check?

Each downloaded file's size against what Smartsheet reported, and that every manifest and export is on disk. In SharePoint, a file counts as verified only when its size and hash match what Smartsheet sent.

Can it back up to SharePoint?

Yes. An admin approves Rowtrace for the company once, an owner of the site grants it that one site, and backups go to a library and folder you pick there.

How long are backups kept?

Each schedule keeps the last 7 completed runs unless you change it. An older run is deleted only after a newer one finishes cleanly, and runs you start by hand are never deleted.

Do I need a server, an agent or an IT deployment?

No. Rowtrace is one code-signed Windows program. Download it, double-click it, paste a Smartsheet API token and choose a folder. There is nothing to install and no account to create.

Which Smartsheet accounts does it work with?

Accounts on smartsheet.com. Smartsheet EU, AU and Gov accounts aren't supported yet.

What doesn't it back up?

Dashboards, and sheet metadata such as formulas and automations. Files linked from Box, Google Drive, OneDrive, Dropbox or a web address have no file to download, so their addresses are listed in the manifest. Sheets in your Sheets folder that aren't in a workspace don't appear yet.
