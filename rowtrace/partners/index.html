What is Rowtrace?

Rowtrace is a Windows app that backs up your Smartsheet sheets, their attachments and the data in your reports to a folder you choose: a local drive, a OneDrive folder or a network share. Each row's attachments are filed in a folder for that row, beside an Excel copy of the sheet, with a manifest that maps every file to its row and records what the row said at the time. It runs on a schedule you set, carries forward what hasn't changed, keeps earlier versions of each attachment, and checks every file it writes against the size Smartsheet reported. Your API token and your data stay on your computer. Rowtrace doesn't restore into Smartsheet; it's the backup you can open, read and hand to an auditor.
