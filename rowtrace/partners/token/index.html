Where does my token go?

To Smartsheet, and nowhere else. Rowtrace needs a Smartsheet API access token, which you generate yourself in Smartsheet under Account → Personal Settings → API Access. Here is everything that happens to it, and to your backup.

OverviewGetting startedYour token and your data

What happens to my token?

  1. You paste it in

    Rowtrace uses the token to call the Smartsheet API, and for nothing else. The only servers Rowtrace talks to are Smartsheet's: its API, and the download links Smartsheet hands back for your attachments.

  2. It's saved, encrypted, on your computer

    Rowtrace saves the token so scheduled backups can run without you. It's encrypted with Windows' built-in data protection (DPAPI), which ties it to your Windows user on this computer. Copied to another computer, or opened by another Windows user, the saved file can't be read. It's kept in %LOCALAPPDATA%\Eskley, outside OneDrive, so it doesn't sync anywhere.

    The limit worth knowing. DPAPI protects the token from other people and other computers, not from other programs running as you. Anything that runs under your Windows user, malware included, could read it. That's true of every app that saves a credential this way, and it's why the next two points matter.

  3. You can take it back at any time

    Revoke the token in Smartsheet under API Access and Rowtrace can no longer reach your account. Choose Forget this account beside the saved account in Rowtrace to delete the local copy.

Which account's token should I use?

Ideally a dedicated account that's shared to what you want backed up, not your own.

A token can do anything its user can do in Smartsheet, and Smartsheet itself recommends a shared account for API work (Smartsheet API authentication guide). A dedicated account also keeps backups running when people change roles: if a user is deactivated, their tokens are revoked with them (Smartsheet Help).

Rowtrace sees exactly what the token's user can see. A token from someone who isn't shared to a workspace won't back it up.

If your plan sets an expiry on every access token (Enterprise plans can, in Admin Center: Smartsheet Help), backups stop when the token expires. Generate a new one and connect again. Whether a scheduled run that hits an expired or revoked token tells you so, and where, isn't verified yet.

Where does my data go?

To the folder you pick, and nowhere else.

There's no Eskley server, no account to create, and nothing for Rowtrace to send usage data to. Your backup is plain folders and files you can open in File Explorer and Excel without Rowtrace installed.

Which Smartsheet accounts does it work with?

Accounts on smartsheet.com only, for now.

Smartsheet's EU, Australia and Gov regions use their own API addresses and their own tokens (Smartsheet Help). Rowtrace doesn't connect to them yet. If your Smartsheet address ends in anything other than smartsheet.com, tell us before you start.

How do I know the app came from you?

Rowtrace is a single code-signed Windows program, and Windows shows its publisher as Eskley LLC.

You'll see it if Windows asks before the first run: under More info, the publisher reads Eskley LLC. You can also right-click Rowtrace.exe, choose Properties, and open Digital Signatures.

If your organization only allows approved software, a signed program may still need your IT team to approve it before it will run. Signing tells them who made it; it doesn't approve it on their behalf.
